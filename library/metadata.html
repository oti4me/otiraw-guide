OtiRAW User Guide

Metadata and keywords

Metadata is the information that travels with a photo: its title and caption, who made it and who owns it, where it was taken, and keywords to find it by.

The Metadata panel

The Metadata panel (right side of the Library, left side of Edit) shows the active photo’s details and lets you edit them. What you type applies to every selected photo; a field shows <mixed> where the selected photos differ.

The menu at the top of the panel chooses what it shows:

ViewShows
DefaultThe fields you use most. Customize… chooses which
IPTCEvery descriptive field: title, caption, headline, creator and contact details, copyright and usage, location, and more
EXIFWhat the camera recorded: exposure, lens, focal length, ISO, date, GPS, and every tag in the file

Editing

ToPress
Start editing metadata⌘I
Add keywords⌘K
Save and go to the next photo, same field⌘]
Save and go to the previous photo⌘[
Save and leave the field⌘Return

While a field has the cursor, letter and number keys type; they don’t flag or rate. An edit is one step for ⌘Z.

⌘] is the quick way to caption a sequence: type, ⌘], type, ⌘].

Keywords

In the Keywords field, separate keywords with commas. As you type, matching keywords from your list are offered; Tab takes the first.

Keyword paths. Write Places > Nigeria > Lagos to file a keyword under its parents. The photo is then found by any level of the path.

Each keyword on a photo is a small chip; click its × to remove it. Lists of names (people shown, for instance) are separated with semicolons.

The Keyword List

The Keyword List panel shows all your keywords as a tree, with how many photos have each.

  • Tick a keyword to add it to the selected photos; untick it to remove it.
  • Type in Filter Keywords to find one.
  • Import Keyword List… and Export Keyword List… read and write a plain text list (one keyword a line, indented with tabs for children), the format most photo applications exchange.

Filter by keyword

The filter bar’s Keywords control shows photos with a keyword, and also No Caption and No Keywords (photos still to do). See Filter, sort and search.

Copy and paste metadata

  1. Select the photo to copy from and choose Metadata › Copy Metadata… (⌥⇧⌘C).
  2. Tick the fields to copy and click Copy. (Save as Template keeps them as a template instead.)
  3. Select the photos to paste onto and choose Metadata › Paste Metadata (⌥⇧⌘V).

Templates

A template fills in several fields at once: your name, copyright notice, contact details and standing keywords, for example.

ToPress
Apply a template to the selection⌘T, then type to find it
Apply the last template again⇧⌘T
Make and change templates⌥⌘T (Metadata › Edit Templates…)

In the Metadata Templates window:

  • New makes a template; Duplicate and Delete do what they say (a deleted template’s file goes to the Trash).
  • Only ticked fields are written; the rest of a photo’s metadata is left alone.
  • Load from XMP… brings in a template from another application’s XMP file, and Save as XMP… writes one out.

A template can also be applied to every photo as it is imported.

Variables

Any field, in the panel or in a template, can contain variables that are filled in for each photo: {date}, {camera}, {name}, {seq}, and every metadata field by its short name: {city}, {creator}, {headline}… The template editor lists them and shows what each gives on the current photo.

Code replacements

A code replacement is a short code that expands into longer text: a player’s number into their full name and team, for example. This is the way sports and event photographers caption quickly.

  1. Make a tab-separated text file: a code, a tab, then what it stands for. More replacements can follow after more tabs.
  2. Add the file in Settings › Metadata › Code replacements › Add Code File….
  3. In any field, type the code between the delimiters: =cc2= becomes its first replacement, =cc2#2= its second.

The delimiter is = unless you change it there. Where two files have the same code, the file added last wins.

Metadata from other applications

OtiRAW reads the metadata other applications wrote: XMP sidecars, and XMP and IPTC embedded in JPEG, TIFF and DNG files. Reading never writes anything.

To have OtiRAW’s metadata seen elsewhere, keep the folder’s marks in XMP sidecars, or turn on writing into JPEG, TIFF and DNG files. Both are explained in How OtiRAW keeps your work.
