OtiRAW User Guide

Import from a card

You never have to import: any folder can be opened where it is. Import is for getting photos off a memory card (or out of another folder) into the place you keep them, renamed, backed up and tagged on the way.

Open it with File › Import Photos… (⇧⌘I) or the Import… button. When a memory card is put in, the Import window opens on it by itself (turn this off in Settings › File Handling › Import › Memory cards).

The Import window

The window reads left to right: where the photos come from, which of them, and where they go.

1. Source (left)

Choose a card under Devices or a folder under Files (Other Folder… for one not listed). Tick Include Subfolders to take in the folders inside it.

2. What to do (top)

ChoiceWhat happens
CopyThe photos are copied to the destination. The source is left as it is. Use this for cards
MoveThe photos are moved to the destination
AddThe photos stay where they are; their folder joins the Folders panel and opens. Nothing is copied or moved

3. Which photos (centre)

Thumbnails of everything in the source, each with a tick.

  • All Photos shows everything; New Photos hides the ones you have imported before.
  • Check All and Uncheck All tick or untick them; click a thumbnail’s box for one.
  • The Thumbnails slider changes their size.

4. Options (right)

File Handling

OptionWhat it does
Build Previews from Raw DataShows the photos only as rendered from their raw data. Off shows the camera’s embedded JPEG at once
Don’t Import Suspected DuplicatesSkips photos imported before (same name, size and capture time) or already at the destination
Make a Second Copy ToCopies every photo to a second folder too, as a backup

File Renaming

Tick Rename Files to rename photos as they are copied, with a template and a Start number. See the tokens in Move, copy, rename and trash.

Apply During Import

FieldWhat it does
TemplateA metadata template to apply to every photo (made in Metadata › Edit Templates…)
Creator, CopyrightWritten on top of the template
KeywordsKeywords for every photo, separated by commas; Places > Nigeria for a path

Destination

Choose the folder to copy into (Choose a Folder…). Into Subfolder puts the photos in a subfolder of it:

  • one of the date layouts, such as 2026/2026-10-23, 2026-10-23 or 2026/10/23; or
  • Custom, a template of your own: / separates folders, and {year}, {month}, {day}, {date} and {camera} are filled in from each photo.

Click Import. The copy runs in the background with its progress in the status line. Every copy is checked against the original before it counts as done.

OtiRAW remembers these choices for next time.

What an import leaves behind

  • The destination folder becomes a shoot, and opens.
  • Previous Import in the Library section shows exactly the photos brought in.

Cull on the card first

To avoid copying photos you will throw away:

  1. In the Import window, choose the card and click Cull in Library….
  2. The card’s photos open in the Library with every view and key. Flag picks and rejects as usual. Nothing is written to the card.
  3. In the bar at the top, click Import Picks (only the picks are ticked) or Import All but Rejected. You are back in the Import window with those photos ticked.
  4. Click Import.

The marks you made come with the photos. If the card is taken out halfway, the marks are kept for when it is back. Done stops culling without importing.

If something is interrupted

Imports, moves and copies are recorded as they go. If OtiRAW quits or the disk is unplugged in the middle, the next launch says An Operation Didn’t Finish and offers:

ButtonWhat it does
FinishCarries on from where it stopped
UndoPuts things back: moved files return, and copies OtiRAW made and checked are removed
LaterAsks again next time

Nothing is deleted that hasn’t been copied and checked.
