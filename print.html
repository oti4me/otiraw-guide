OtiRAW User Guide

OtiRAW User Guide

OtiRAW is a photo application for people who shoot raw. It browses and culls large shoots quickly, edits raw photos without ever changing the files, builds layered compositions, and prints, exports and publishes the results.

This guide explains every part of it: what each workspace is for, where each control is, and how the features work together.

The four workspaces

OtiRAW has four workspaces. You move between them with the four buttons at the left end of the bar above the filmstrip, or from the keyboard.

WorkspaceWhat you do thereKey
LibraryBrowse folders, cull, rate, keyword, filter, import and organise⌥⌘1
EditDevelop a raw photo: tone, colour, detail, geometry, masks, retouching, looksD
ComposeBuild a layered picture: photos, text, shapes, adjustments, cut-outs, retouching⌘E
PrintLay photos out on pages and print them or save them as PDF, JPEG or TIFF⌘P

Export, Publish, HDR merge, Panorama and Settings open as windows over whichever workspace you are in.

What makes OtiRAW different

  • No import step. Point OtiRAW at a folder and its photos are there. Nothing is copied into a catalogue first. (You can copy photos off a memory card with Import, but you never have to.)
  • Your files are never changed. Stars, flags, keywords and edits are kept beside the photos, not in them. See How OtiRAW keeps your work.
  • Everything is undoable. Marks, metadata, edits, stacking and set changes all go through one Undo (⌘Z).
  • It runs on your computer. The models behind the AI masks, Assist, denoise and retouching run locally. Nothing is uploaded unless you publish it yourself.

Install OtiRAW

What you need

  • A Mac with Apple silicon (M1 or later).
  • macOS 11 (Big Sur) or later.

OtiRAW does not run on Intel Macs. Windows and Linux versions are not released yet.

Install it

  1. Open the disk image (OtiRAW-….dmg).
  2. Drag OtiRAW onto the Applications folder in the window that opens.
  3. Eject the disk image.

Open it the first time

The app is not yet signed with an Apple developer certificate, so macOS refuses to open it the first time and says it can’t check it for malicious software.

  1. Double-click OtiRAW in Applications. Close the warning.
  2. Open System Settings › Privacy & Security.
  3. Scroll to the message about OtiRAW and click Open Anyway.
  4. Confirm with your password or Touch ID.

You only do this once. After that OtiRAW opens like any other app.

Download the models you want

OtiRAW’s AI features (subject and sky masks, Assist, portrait retouching, removal fills, depth effects, the generative tools) use models that run on your Mac. None is included in the installer, so the download stays small.

Open OtiRAW › Models… (or Settings › Models) and download the ones you want. Each row says what the model is for, how large it is and its licence. Everything else in the app works without them. See Models.

Update it

Install a newer disk image the same way and replace the old app. Your settings, presets, looks and library stay where they are: they are kept outside the app (see Where OtiRAW keeps things).

Remove it

Drag OtiRAW from Applications to the Trash. To remove its settings and downloaded models too, delete the OtiRAW folder in ~/Library/Application Support. The OtiRAW folders inside your photo folders hold your stars, flags and edits: keep them unless you want those gone.

Your first shoot, start to finish

This page walks through a whole job once: open a folder, pick the keepers, edit one, apply the edit to the rest, and export. Each step links to the page that covers it fully.

1. Open the photos

If the photos are already on a disk: choose File › Open Folder… (⌘O), or drag the folder onto the OtiRAW window. The photos appear at once. The folder is added to the Folders panel so it is there next time.

If they are still on a memory card: put the card in. The Import window opens on it (if it doesn’t, choose File › Import Photos…, ⇧⌘I). Choose where to copy the photos, then click Import. See Import from a card.

While you start working, OtiRAW builds screen-sized previews of the folder in the background (the status line says Building previews). You don’t have to wait.

2. Pick the keepers

Press E for the loupe (one photo, large) and step through with → and ←.

KeyMark
PPick
XReject
URemove the flag
1 to 5Stars (0 removes them)
6 to 9Colour labels: red, yellow, green, blue

Useful while culling:

  • Z zooms to 100 % and back, to check focus.
  • Hold ⇧ with a marking key to mark and move to the next photo. Or turn on Photo › Auto Advance to do that every time.
  • C compares two photos side by side; N shows the selected photos together to narrow them down.

When you are done, show only the picks: click Filter in the filter bar and choose Picked. See Stars, flags and labels and Filter, sort and search.

3. Edit one photo

Select a pick and press D for the Edit workspace.

  1. In Essentials, click Auto for a starting point, or set Exposure yourself.
  2. Fix the colour: choose a WB preset, drag Temp and Tint, or press W and click something that should be neutral grey.
  3. Shape the tone with Contrast, Highlights, Shadows, Whites and Blacks.
  4. Press R to crop and straighten; press Enter when done.
  5. Press \ to see the photo as it was before, and again to come back.

Nothing you do here changes the raw file. See The Edit workspace.

4. Give the others the same edit

  1. With the edited photo active, press ⌥⌘C (Copy Settings) and tick the sections to copy.
  2. Select the other photos in the filmstrip (⇧-click for a range, ⌘-click to add one).
  3. Press ⌥⌘V (Paste Settings).

Or select them all first and click Sync…. See Presets, copy, sync and Match Look.

5. Export

  1. Select the photos to export.
  2. Choose File › Export… (⇧⌘E).
  3. Pick a preset or set the format, size and folder yourself.
  4. Click Export.

The export runs in the background while you keep working; the status line shows its progress. See Export.

  • Let OtiRAW suggest picks and rejects: Assist.
  • Adjust part of a photo: Masks.
  • Add text, borders or several photos to one picture: The Compose workspace.

How OtiRAW keeps your work

OtiRAW never changes your raw files. Everything you add to a photo (stars, flags, labels, keywords, captions, edits, snapshots, virtual copies) is kept beside the photos. This page explains where, so you can back it up, move it and share it with other applications.

Two ways to keep a folder’s marks

Each folder of photos keeps its marks one of two ways.

An OtiRAW folderXMP sidecars
What is writtenOne file, in a folder called OtiRAW inside the photo folderA small .xmp file beside each photo
ClutterNothing beside the photosOne extra file per photo
Other photo applicationsDon’t see the marksRead the stars, labels, keywords and captions
Best forWorking in OtiRAW alone; very large foldersSharing a folder with other applications

Either way the marks travel with the folder: copy or move the folder to another disk or computer and they come along.

Choose for a folder

  • In the bar above the filmstrip, open Keep ratings, flags and labels in and choose An OtiRAW folder or XMP sidecars.
  • Or right-click the folder in the Folders panel and use Keep this folder’s marks in.

A folder that already has XMP sidecars keeps using them unless you change it.

Choose for new folders

Settings › File Handling › Ratings, flags and labels › New folders keep them in sets what a folder you open for the first time uses.

Have both

Turn on Settings › File Handling › Ratings, flags and labels › XMP sidecars: Also write them when marks are kept in an OtiRAW folder to keep the marks in the OtiRAW folder and write sidecars for other applications. To write a folder’s sidecars once, right-click it and choose Save Metadata to XMP Now.

Other choices in the same place:

  • New sidecars are named IMG_1.xmp (what most applications use) or IMG_1.CR3.xmp (keeping the photo’s extension).
  • Write rejected photos as rating −1, the usual way to show a reject in XMP.
  • Also write metadata into JPEG, TIFF and DNG files: into the files themselves, for applications that read only what is inside a file. This is off unless you turn it on, and other raw files are never written.

Edits

A photo’s edit is a list of settings, kept with its marks: in the folder’s OtiRAW folder, or in its XMP sidecar. The raw data is rendered through those settings every time the photo is shown or exported. That is why:

  • you can undo or reset an edit at any time, years later;
  • an edit takes almost no disk space;
  • a virtual copy (a second edit of the same photo) costs nothing but its settings.

A photo’s snapshots are kept in its edit. Its history is kept for the next launch, up to the number of steps set in Settings › Performance › Edit History.

Folders you can’t write to

If a folder is read-only (a locked disk, a network share without permission), OtiRAW keeps its marks on your computer instead and says so. They are matched to the folder when it is opened again.

Memory cards

A card culled before importing is never written to. The marks you make are remembered and come with the photos when you import them. See Import from a card.

JPEGs beside raw files

A JPEG with the same name as a raw file is treated as part of that photo, not as a second photo. To show them separately, turn on Settings › File Handling › Folders › JPEGs next to raw files as photos of their own.

Slow disks and cards

OtiRAW reads memory cards, network shares and hard disks gently, a few files at a time, and SSDs fast. Settings › File Handling › Read its disk lets you force one or the other.

Previews

The first time a folder is open, OtiRAW saves screen-sized previews of it to a cache on your disk, in the background. The status line shows Building previews and then Previews ready. After that the folder opens and scrolls at full speed, now and next time.

Raw photos first show the JPEG the camera stored inside them (a small Embedded badge says so), then OtiRAW’s own render of the raw data takes its place. Two settings change this:

  • Settings › Culling › Loupe › Show raw files rendered from their raw data: off keeps the camera’s preview in the loupe, the quickest for culling.
  • Settings › Culling › Loupe › Build previews from raw data: on shows only OtiRAW’s renders, in the grid and filmstrip too.

Sets

A set is a named group of photos. A photo can be in any number of sets, and deleting a set never touches photos.

There are two kinds:

  • A set holds the photos you put in it.
  • A smart set holds whatever matches a filter (for example “5 stars, green label”) and updates itself as you mark photos.

And two places a set can live:

  • in a shoot (kept in the shoot’s folder, travelling with it), or
  • in the library (available everywhere, able to hold photos from many folders).

In the folder’s OtiRAW folder or in XMP sidecars, your choice per folder. Marks kept in XMP sidecars are read by other photo applications. See How OtiRAW keeps your work.

Getting rid of the rejects

Photo › Delete Rejected Photos… (⌘⌫) moves every photo flagged as rejected to the Trash, after asking. They go to the system Trash, where you can still put them back. See Move, copy, rename and trash.

Suggested workflows

One pass, picks only. Go through in the loupe with Auto Advance on. Press P for keepers and → for the rest. Filter to Picked at the end.

Reject first. First pass: X on anything unusable (missed focus, blinks). Filter to hide rejects. Second pass: stars on what is left.

Rounds. In a shoot, flag picks for Round 1, then give three stars or more to the best of them for Round 2. The shoot’s smart sets fill themselves as you go.

Assist can do the first pass for you, as suggestions you approve.

Filter, sort and search

Filtering, sorting and searching decide which photos are shown and in what order. They apply to the grid, the filmstrip and every view, and they stay as they are when you open another folder, until you clear them.

The filter is in the bar above the filmstrip (across the top in some layouts). It has:

Click the comparison beside the stars to switch between Rating is at least, at most, exactly and Unrated only.

The bar says how many photos are shown out of how many. Moving through photos, selecting a range and Select All only ever touch the photos shown.

Turn the filter off and on

⌘L (Filters On/Off) turns the whole filter off and back on, keeping what you set. If the grid is empty with the message “No photos match the filter”, ⌘L brings the photos back.

Filter presets

Open the Filter menu at the start of the bar:

  • Ready-made presets: Picked, Rejected, Unflagged, Rated, Unrated, Labelled, Filters Off.
  • Save Current Settings as New Preset… keeps the filter you have built under a name.
  • Delete Preset removes one of yours.

A filter can also be kept as a smart set, which lists the photos that match and updates itself.

Search

Press ⌘F and type. Search looks in file names, cameras, lenses, keywords, titles and captions.

  • A photo is found when it has every word you type.
  • Each word matches the start of a word: lag finds “Lagos”; 85 finds “85mm”.

The magnifier in the bar shows or hides the search field; the × in it clears the search.

Assist: help with culling

Assist looks at every photo and tells you what it found: which frames are sharp, where eyes are closed, which photos are the same shot, and which of each group is best. It only ever suggests. Nothing is marked or deleted until you say so.

Everything is measured on your computer. No photo leaves it.

Faces, eyes and similar-photo groups need Assist’s models. Download them in Settings › Models. Without them Assist still measures sharpness, motion and exposure.

Groups and suggestions

Assist gathers photos into groups: frames of the same shot, and shots of the same scene. Within a group it judges each photo against the others, so “soft” means softer than the group’s sharpest, and “eyes closed” means closed here while open in the other frames.

Each photo then gets a suggestion with its reasons:

  • a suggested pick: the best of its group;
  • a suggested reject: with a reason such as eyes closed, soft, motion blur, a face cut off, or faces much darker or brighter than the group’s;
  • to review: a close call Assist won’t decide.

  • Compare Group (⇧C) and Survey Group (⇧N): open the group in Compare or Survey.

The Process is the version of OtiRAW’s default rendering a photo’s edit uses. A newer process changes only what it improves, and an edit you made keeps the process it was made with, so old edits never shift.

The tone curve maps each brightness in the photo to a new one. It gives finer control over contrast than the Essentials sliders, and works on top of them.

The Curve section has five curves, chosen with the Adjust buttons above the graph: a ring with a curve in it for the parametric curve, then a plain ring each for the point curve and the red, green and blue channels.

Four sliders move four regions: Highlights, Lights, Darks and Shadows.

  • Drag a slider, or drag up or down on the graph to move the region under the pointer.
  • The three split handles under the graph (Split Dark, Split Mid, Split Light) set where one region ends and the next begins.
  • Click Region to show or hide the sliders.

The parametric curve can’t be pushed into odd shapes, so it is the safe way to add or soften contrast.

Channel curves

The red, green and blue curves change one channel at a time, which shifts colour as well as tone:

  • lifting red in the highlights warms them; lowering it cools them;
  • an S on blue adds blue to highlights and yellow to shadows.

For colour work by hue, the Color Curves window is easier to control.

In masks

A mask can have its own tone curve. See Masks.

Point Color

Point Color (beside Mixer at the top of the Color Mixer) adjusts one colour you pick, together with the colours like it.

  1. Click the Point Color Dropper and click the colour on the photo. (Esc stops picking.) A swatch is added.
  2. In the colour field, drag across for Hue Shift and up and down for Sat. Shift; drag the bar beside it for Lum. Shift. Hold ⌥ for finer moves.
  3. Set how wide the selection is with Range, or open Show Ranges for separate Hue Range, Saturation Range and Luminance Range.
  4. Tick Visualize Range to see the photo grey wherever the swatch selects nothing.

Each swatch’s menu has Reset Swatch, Delete Swatch, Delete All Swatches, and Make Mask from Swatch, which turns the selection into a mask you can apply any adjustment to.

Colours too close to grey or black can’t be picked: Point Color selects by hue.

Channel Mixer

  • Color: each output channel (red, green, blue) is a mix of the three input channels.
  • Black & White: one mix of red, green and blue makes the grey. More red lightens skin and darkens skies, as a red filter does on black-and-white film.

Total shows what the three add up to; 100 % keeps the brightness.

Calibration

Adjusts how the camera’s own primaries are read: Shadows Tint, and Hue and Saturation for the red, green and blue primaries. Small moves here change the whole character of a photo’s colour, which is why many presets use it.

Black and white

Three ways, from quickest to most controlled:

  1. Channel Mixer › Black & White: set the mix.
  2. The Looks tool’s Black & White with a colour filter, with or without a film stock.
  3. A black-and-white film stock in the Looks tool, with its own grain and tone.

Detail: sharpening and noise

The Detail section sharpens the photo and reduces its noise. Judge both at 100 %: press Z.

Sharpening

SliderWhat it does

Sharpening works on brightness only, so it doesn’t add colour fringes.

A good order: set Amount, then Radius for the kind of detail, then raise Masking until smooth areas stop looking gritty.

Capture Sharpening

Capture sharpening undoes the slight softness every lens and sensor adds, before anything else is done to the photo. It is a correction, not an effect: a little goes a long way, and it should not be used to make a soft photo look sharp.

Geometry

Miniature

Makes a scene look like a small model, by keeping one zone sharp and blurring the rest. It works best on photos taken from high up.

  • Band keeps a band across the photo sharp; Ellipse keeps an ellipse sharp.

Remove, heal and lights

The Retouch & Light group in the Masking tool (⇧W) holds the tools that change what is in the photo: taking things out, cloning, cleaning sensor dust, and adding light.

All of them are part of the edit, like any slider: they can be changed, hidden or deleted later, and they are applied before the photo’s colour and tone, so later edits apply to them too.

Remove

Remove takes an object out and fills the gap with what could be behind it.

Paint it out

  1. Click Remove.
  2. Paint over what to remove. As you let go, the stroke fills.

Each stroke is a spot. Click a spot to select it; Delete Spot takes it away; ⌥-paint erases from the spots. A removal holds up to 64 spots.

Select an object (needs the Segment Anything model)

  1. Click Select Object.
  2. Click the object, paint over it, or drag a box round it. What is selected is tinted, a little past its edge so none of it is left behind.
  3. Tick Remove Its Shadow if the darker ground joined to the object should go too.
  4. Click Remove.

Change Selection shows the spot not yet removed, to change what is selected.

Portrait

The Portrait tool (⇧F) retouches faces: skin, eyes, mouth and shape. It finds every face in the photo and works on all of them at once, or on each separately.

Portrait needs the Select People models. Download them in Settings › Models, then restart OtiRAW.

HDR merge

An HDR merge combines several exposures of the same scene (a bracket) into one photo that holds everything from the deepest shadow to the brightest highlight.

The result is a new raw file: a DNG saved beside the originals as <name>-HDR.dng. You edit it like any raw photo, with far more room: its Exposure slider goes to ±10 stops.

Shoot for it

  • Shoot three or more frames a stop or two apart, on one camera and lens, without changing aperture or focus.
  • A tripod gives the cleanest result. Hand-held brackets work too, with Auto Align.

Find the brackets

OtiRAW recognises a bracket from its metadata: frames shot within a couple of seconds of each other, at exposures a stop or so apart. With Auto-Stack Brackets on (Photo › Auto-Stack by Capture Time…), each bracket is a stack in the grid.

Merge

  1. Select the frames of a bracket, or its stack.
  2. Choose Photo › Photo Merge › HDR… (⇧⌘H).
  3. Check the preview and set the options.
  4. Click Merge.

The merge runs in the background; you can keep working.

Panorama

A panorama stitches overlapping photos into one wide (or tall) picture. Like an HDR merge, the result is a new DNG you edit as a raw photo, saved beside the originals.

Shoot for it

  • Overlap each frame with the next by about a third.
  • Keep exposure, focus and white balance fixed (manual exposure is best).
  • Turn the camera about the lens, not about yourself, to avoid near objects shifting against far ones.

Stitch

  1. Select the overlapping photos.
  2. Choose Photo › Photo Merge › Panorama… (⇧⌥M).
  3. Check the preview and set the options.

Edit the panorama

Open the DNG in Edit. Everything works as on any raw photo. Two things are often useful:

  • Geometry: Upright or a guide to level the horizon or straighten verticals the projection curved.
  • Crop: to trim the edges, or change what Auto Crop chose.

If it fails

  • “Select two overlapping photos or more to stitch”: too few photos selected.
  • A stitch that can’t find how the photos join usually means too little overlap, or a frame with nothing to match on (plain sky, plain water). Leave that frame out, or reshoot with more overlap.
  • A panorama can only be re-merged while its photos are still in the same folder.

Tips

  • Fill and Expand work on what the canvas shows: hide layers you don’t want considered.
  • A selection a little larger than the object gives the fill room to blend.

  • A filled area is ordinary pixels afterwards: retouch a seam with Heal or a soft mask.

Publish to your accounts

Publishing sends an export’s files straight to somewhere of yours: your own server or storage, your website, a gallery host or a social account. It is part of Export, so everything Export does (resizing, sharpening, naming, metadata) applies to what is sent.

OtiRAW signs in as you, with details you give it. It has no server of its own in between and carries no keys of its maker’s.

1. Add an account

Open File › Publishing Accounts… (⌥⇧⌘S), which is Settings › Publishing.

  1. Click to add an account and choose the service.
  2. Fill in the fields the service needs (below).
  3. Click Check Sign-In. OtiRAW connects and says whether it worked.
  4. Click Save.

Edit and Remove change or delete an account later.

Passwords, keys and tokens are kept only in the macOS Keychain, never in a file.

2. Send from Export

In the Export window, select a recipe and open Location:

  • Send To: choose the account.
  • Place: a folder or album in the account for this recipe’s files (where the service has them).

Then export as usual. The files are written to the export folder first, then sent one at a time.

  • The status line shows Sending 3 of 12, with Stop. Stopping leaves what was sent where it is.
  • A file that fails says why and doesn’t stop the rest.
  • At the end a message says what was sent (“Sent 12 files to My Site”).
  • If a service won’t take a recipe’s files (a PSD to a blog, a file over its size limit), the Export window says so before anything is exported.

Nothing is ever published on its own. Sending happens only as part of an export you start.

Printing darker than the screen?

Screens are usually far brighter than paper in a room. In order:

  1. Lower your screen’s brightness to a level meant for print work.
  2. Check that only one of OtiRAW and the printer is managing colour.
  3. Use the paper’s own profile, not a generic one.
  4. For what remains, use Print Adjustment, so the fix is for the print alone and your edits stay right for the screen.

DCTL files

OtiRAW translates a DCTL (the colour-transform files used in video grading software) into a plugin. Its controls become the plugin’s: sliders and value boxes as sliders, check boxes as ticks, combo boxes as menus, and a colour picker as red, green and blue sliders.

Not every DCTL translates: one that relies on features outside a per-pixel transform is listed with the reason it couldn’t be loaded.

What a plugin can and can’t do

  • It changes colour and tone, and (if it asks to) can read nearby pixels for blurs, glows and sharpening.
  • It can use one LUT kept in its folder.
  • It can’t read your files or use the network. A plugin is a shader that runs on the graphics processor and nothing else.

Write your own

A plugin is a folder with two files:

plugins/
  my-look/
    plugin.toml     its name, where it runs, its sliders
    plugin.wgsl     the shader: one function, apply

A minimal plugin.toml:

id = "com.example.my-look"
name = "My Look"
version = "1.0.0"
api = 1
place = "display"

[[param]]
key = "amount"
name = "Amount"
min = 0
max = 100
default = 50

And plugin.wgsl:

fn apply(c: vec4f, p: Params) -> vec4f {
    let a = p.amount / 100.0;
    return vec4f(sat(c.rgb, 1.0 - a), c.a);
}

c is the pixel (linear red, green, blue and alpha); p holds your sliders’ values by their keys; return the new pixel.

placeThe plugin works onUse it for
sceneScene light, before the display transform: linear, no upper limitChanges that should roll off naturally, like exposure or a filter on the lens
displayDisplay values, 0 to 1, after the display transformGrading that should feel like a print’s or video’s

OtiRAW provides helper functions for brightness, saturation, hue, OkLab colour, encoding to and from video values, and reading neighbouring pixels. The four stock plugins are worked examples to copy from.

Edit the files, click Reload, and the change shows at once: no restart, nothing to compile.

Moving to a new computer

  1. Copy your photo folders, including the OtiRAW folders or .xmp files inside them.
  2. Copy ~/Library/Application Support/OtiRAW (without models, if you like).
  3. Install OtiRAW on the new Mac and open it.
  4. If the folders are in a different place, add them again with File › Open Folder…, or right-click an offline folder and choose Find Missing Folder….
  5. Sign in to your publishing accounts again: passwords are in the old Mac’s Keychain and don’t travel in the files.
  6. Download the models you use.

Moving photos

Move and rename photos inside OtiRAW (Photo › Move to Folder…, Rename Photos…) and their sidecars, JPEGs, marks and edits go with them.

If you move a whole folder in the Finder, everything inside travels with it: point OtiRAW at the new place with Find Missing Folder….

If you move or rename individual files in the Finder, their XMP sidecars must be moved and renamed with them, and marks kept in the folder’s OtiRAW folder may no longer be matched to them. Prefer doing it in OtiRAW.

Troubleshooting

Opening the app

“OtiRAW can’t be opened because Apple cannot check it for malicious software.” The app isn’t signed with an Apple developer certificate yet. Open System Settings › Privacy & Security, scroll to the message about OtiRAW, and click Open Anyway. You only do this once. See Install OtiRAW.

It won’t run on my Mac. OtiRAW needs a Mac with Apple silicon (M1 or later) and macOS 11 or later. It doesn’t run on Intel Macs.

Photos

The grid is empty.

  • If the message is “No photos match the filter”, press ⌘L to turn the filter off, and clear the search field.
  • If the folder’s photos are in subfolders, turn on File › Show Photos in Subfolders.
  • Check that the files are of a kind OtiRAW opens: see Cameras and file types.

A folder is greyed out and says Offline. Its disk isn’t connected. Reconnect it. If the folder was moved, right-click it and choose Find Missing Folder….

A photo looks different from the camera’s screen. The camera shows its own JPEG rendering; OtiRAW renders the raw data its own way. The Embedded badge marks a photo still showing the camera’s preview. To start closer to the camera’s look, try a look in the Looks tool.

Photos look different in the grid than in the loupe. The grid may show the camera’s embedded preview while the loupe shows OtiRAW’s render. Turn on Settings › Culling › Loupe › Build previews from raw data to show OtiRAW’s render everywhere.

“Raw helper missing”. Some cameras’ files are read by a helper inside the app. Reinstall OtiRAW to put it back. Until then those photos show their embedded previews.

Photos added in the Finder don’t appear. Right-click the folder and choose Synchronize Folder.

Marks and metadata

“Marks … can’t be saved”. The folder can’t be written to: the disk is full, locked, or read-only. Your marks are held and written when the folder can be. Free some space or check the disk’s permissions.

Another application doesn’t see my stars and keywords. The folder keeps its marks in an OtiRAW folder, which other applications don’t read. Switch it to XMP sidecars, or right-click the folder and choose Save Metadata to XMP Now. See How OtiRAW keeps your work.

Marking keys type letters instead. A text field has the cursor. Press Esc or ⌘Return to leave it.

Marks made in another application don’t show. OtiRAW reads XMP sidecars when a folder opens. Choose Synchronize Folder to read them again.

Editing

Sliders feel slow.

  • OtiRAW draws a quick draft while you drag and the full picture when you stop; a short pause after letting go is normal on very large files.
  • Close other heavy applications. Lower Settings › Performance › Memory › Loupe previews if the Mac is short of memory.
  • The AI denoiser takes a few seconds the first time a photo is shown with it. After that, editing is at normal speed.

A mask or tool says a model isn’t installed. Download it in Settings › Models. See Models.

Subject, Sky or People selects the wrong thing. Add a part to correct it: Subtract a brush stroke over what was wrongly included, or Add one over what was missed. Or try another model for that job, if you have one (Settings › Performance › AI masks).

Lens Correction says “No profile for this lens”. OtiRAW has no profile for that camera and lens. Correct by hand in the Geometry tool (Manual › Distortion) and with Defringe.

I can’t undo. Undo covers what you have done since OtiRAW started, plus each photo’s saved history. Use the History panel to go back further in a photo’s edit, or Reset All to start over.

An old edit looks slightly different after an update. It shouldn’t: edits keep the process version they were made with. If a note offers Update to Current Process, the photo is still on its old one until you choose to update.

Colour and printing

Colours look more saturated in OtiRAW than in a web browser. On a wide-gamut screen OtiRAW shows colours beyond sRGB. Export in sRGB for the web, and use Soft Proof (⌘Y) set to sRGB to see what others will see.

Prints come out too dark. Almost always the screen is too bright for print work. See Print.

Prints have a colour cast. Colour is being managed twice, or not at all. Either OtiRAW manages it (choose the paper’s profile and turn the printer’s colour management off) or the printer does (Managed by Printer), never both.

“No printer profiles are installed”. Install your paper’s ICC profile from the printer’s driver or the paper maker’s website.

Export and publishing

“Choose a folder to export to” / “Tick a recipe to export with”. The Export button waits for both. Choose a Folder under Location, and tick at least one recipe.

An exported file is larger or smaller than expected. Check the recipe’s Size mode and Don’t Enlarge, and the Summary on the right of the Export window, which gives each recipe’s pixel size before you export.

Publishing: “Won’t be sent”. The service doesn’t take that recipe’s files: the wrong format, or a file over its size limit. The message says which. Use a JPEG recipe, or a smaller size.

Publishing: the sign-in check fails.

  • Read the service’s own reason in the message.
  • For WordPress and Bluesky, use an application password, not your account password.
  • For SFTP, RSA keys aren’t supported: use a password, or an Ed25519 or ECDSA key.
  • For SFTP, “…’s key isn’t the one this account knows” means the server presents a different key from the one remembered. If the server was set up again, check the sign-in again to take its new key. If it wasn’t, something may be between you and it: find out before sending anything.

Instagram or Threads couldn’t fetch the picture. They download each picture from your hosting account’s Seen At address. Open that address in a browser: if the picture doesn’t load there, fix the address or the host’s permissions.

Models and generators

A model won’t download. Check your internet connection and free disk space, then try again. If the models’ folder is on an external drive, make sure it is attached.

Generative Fill says “No generator yet”. Add one in Edit › Generators…: a built-in model downloaded in Settings › Models, your own server, or a service with your key. See Generative tools.

A generation runs out of memory. Large generative models need a lot of memory. Use a smaller model, a smaller canvas, or a service.

Finding out more

The error log. Settings › General › Error log shows where OtiRAW logs warnings, errors and crashes, a file a day. Send the day’s file with a problem report.

Memory. Help › Memory Use… shows what OtiRAW holds in memory.

Start with defaults. If a setting seems to be the cause, use Restore Defaults on that Settings tab. See Where OtiRAW keeps things.
